# RideBits Release Tracker

Mobile-first release tracker built with Next.js, Tailwind CSS, and Supabase. Installable as a PWA.

## Setup

1. Create a Supabase project.
2. Run the SQL in `supabase/schema.sql` against it (SQL editor or `supabase db push`).
3. Copy `.env.local.example` to `.env.local` and fill in your project URL and anon key.
4. `npm install`
5. `npm run dev`
